# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind, assume good faith, and take disagreement to the substance
rather than the person. Harassment of any kind is not tolerated, in the issue
tracker, in pull requests, or anywhere else this project is discussed.

Report a problem by opening an issue, or privately to the address in the app's
Settings → About → Contact.
